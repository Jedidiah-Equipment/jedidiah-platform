# Read Machine hours

1. Find and open the Machine in **Machines**.
2. Check the hours and their status. **Synced** with a green tick means the reading was accepted by the server; **Queued** means it is still on this phone. The main number shows the newest known reading, including a queued capture.
3. Check **Reading history** for earlier captures. A capture marked **Needs attention** must be resolved from [Needs attention](./resolve-queued-readings). Offline, synced readings come from saved history; connect and open the Machine beforehand to save it.
4. Choose **Capture reading** to [record the current meter value](./capture-a-reading).
