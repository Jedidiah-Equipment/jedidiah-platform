# Maintain Measure Types

1. In Jedidiah Contracting, open **Measure Types**.
2. Choose **New measure type**, enter the **Name**, and choose **Save**. Names must be unique, ignoring letter case.
3. Drag a Measure Type by its handle to change the order **Add measure** and the Rate Card's **Measure type** picker show. The order saves as you drop.
4. Open a Measure Type to correct its Name. Changes save automatically; check the save status before leaving.
5. Choose **Delete measure type** only while no Rate uses it. A Measure Type referenced by a Rate cannot be deleted.
