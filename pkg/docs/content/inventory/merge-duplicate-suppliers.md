# Merge duplicate Suppliers

Procurement Managers, Administrators, and Super Administrators can merge a duplicate Supplier into the Supplier that should remain.

1. Open the duplicate Supplier that should be removed.
2. Click **Merge into…**.
3. Search for and select the Supplier that should remain, then click **Continue**.
4. Review the Part and Purchase Order counts, then click **Merge supplier**.

Every Part and Purchase Order moves together, empty contact fields on the remaining Supplier are filled from the duplicate while existing values stay unchanged, and the duplicate is deleted permanently with no undo.
