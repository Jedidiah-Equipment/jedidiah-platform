# Triage labels

Use these tracker labels whenever an engineering skill mentions a canonical triage role.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Triage uses one state role and one category (`bug` or `enhancement`) per triaged issue. Existing
labels such as `backlog`, `needs-spec`, business labels, and `wayfinder:*` keep their separate meanings.
