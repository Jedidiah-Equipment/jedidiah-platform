# Read Machine hours

1. Find and open the Machine in **Machines**.
2. Check **Latest synced hours** and **Reading history**. Offline, these show the last saved history; connect and open the Machine beforehand to save it.
3. Check any **Queued** captures separately: they are still on this phone. A capture marked **Needs attention** must be resolved from [Needs attention](./resolve-queued-readings).
4. Choose **Capture reading** to [record the current meter value](./capture-a-reading).
