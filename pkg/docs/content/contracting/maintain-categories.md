# Maintain Categories

1. Open **Categories** in Jedidiah Contracting.
2. Choose **New category**, enter its **Name**, and choose **Save**. A name already used by another Category is rejected regardless of letter case.
3. Open a Category to change its **Name**. Changes save automatically.
4. As a Contracting admin or super-admin, enter the **Preset rate (R/hour)**. Use a nonnegative amount in rands per hour; a new Category starts at zero. The field is hidden without rate read access and only rate managers can edit it.
5. Resolve any validation or save error before leaving.
6. To remove an unused Category, choose **Delete category**. Categories linked to Machines cannot be deleted; move those Machines to another Category first.

Categories group Machines and supply their Preset Rate. Implement Type is separate; maintain it through [Implements](./maintain-implements).
