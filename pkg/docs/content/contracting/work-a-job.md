# Work a Job

1. Open **Jobs**. Your open Jobs are listed, newest first. Search by Job, customer, or farm; use the filter to pick one stage, such as **Awaiting pricing**; and sort by **Newest** or **Name**.
2. Open the Job. Each Machine shows **Planned**, **On site**, or **Left site**.
3. To start a planned Machine, choose **Start — capture arrival** and [capture the reading](./capture-a-reading). Change the Implement or Driver first if they differ from the plan.
4. To stop it, choose **Stop — capture departure**.
5. To add a Machine that was not planned, choose **Add machine**, pick the Machine, attach an Implement if it tows one, confirm the Driver, and confirm with **Add machine**. It joins the list as **Planned**; start it as in step 3 when it arrives. A Machine still on another Job can be planned but cannot start until it leaves there. A Machine that left can be added again the same way.
6. To read or add to the Job's notes, switch from **Details** to **Activity**: choose **Add Note**, type it or say it as a Voice Note, and choose **Send**. A Foreman can add one until the Job is Priced. See [Catch up on Activity](./catch-up-on-activity).

The Jobs screen needs a connection; without one, [keep a Field Note](./keep-a-field-note).
