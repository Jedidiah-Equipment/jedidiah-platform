# Read Machine hours

1. Find and open the Machine in **Machines**. It opens on **Details**.
2. The main number is the Machine's latest reading, with when it was read.
3. **Service** shows whether a service is due, the **Next service due** hours from the dash sticker, the hours to go (or how far it is overdue), and the **Service interval**.
4. **Busy with** shows the Job the Machine is on site on now, with its customer, farm and arrival time, and is hidden when the Machine is on no Job. Choose it to open that Job.
5. Choose **Readings** to see every earlier reading, newest first, each marked **Photo-backed** or **Missing Photo Evidence**, and **Disputed** where it applies. Scroll down to load older ones.
6. Choose **Capture reading** on **Details** to [record the current meter value](./capture-a-reading).
