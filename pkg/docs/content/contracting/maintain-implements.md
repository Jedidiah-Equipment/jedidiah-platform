# Maintain Implements

1. Open **Fleet → Implements** in Jedidiah Contracting.
2. Choose **New implement** and select its **Category**. Only Implement categories are offered; add one in [Categories](./maintain-categories) if none fits.
3. The **Code** fills in from the Category name and the next free number, such as `GRAVEL-TRAILER-3`. Keep it or type your own before saving.
4. Choose **Save**. Codes display uppercase; a Code already used by another Implement is rejected regardless of letter case.
5. Open an Implement to change its Code, Category, or Notes. Changes save automatically; resolve any validation or save error before leaving. A Category change never rewrites the Code.
6. To permanently withdraw it, choose **Retire implement**, enter a **Retirement reason**, and choose **Retire**. Its history remains available and it disappears from active pickers. Retirement cannot be undone.
7. Use **Delete implement** only for a never-used entry. If linked history blocks deletion, retire it instead.
8. Choose **Retired** in the fleet status filter to find retired Implements.

An Implement is an un-metered attachment: it has no hour readings, rate, or availability of its own. Fleet changes require Contracting fleet management access.
