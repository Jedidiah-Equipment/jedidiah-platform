# Start from the Dashboard

The Dashboard is the first screen of Jedidiah Contracting on the web. It shows only what needs a person now and refreshes itself every minute.

1. In Jedidiah Contracting, open **Dashboard**.
2. Read the counts. Select one to open its list already filtered:
   - **Looks finished** counts the Jobs whose Machines have all left, waiting for sign-off.
   - **Awaiting pricing** counts the Completed Jobs waiting to be priced.
   - **Awaiting invoice** counts the Priced Jobs waiting for an Invoice Number.
   - **Reading exceptions** counts the readings waiting for review.
3. Read **Jobs needing a look**: open Jobs with an open Gap Flag or a reading the evidence does not confirm, the critical ones first. Select a Job Number to open the Job.
4. Read **Workshop**: every Breakdown not yet Fixed, Code Red first and then the longest waiting, with its Mechanic or **Unassigned**. Select one to open the Breakdown.
5. Read **Service due**: the Machines that are Service Due Soon or overdue, overdue first and then the fewest hours to go. Select a Machine to open it.
6. Choose **View all** on a list to open the full list showing the same records.

A count or list you do not see is one your role does not act on. Anything over a period, such as utilisation, is on **Reports**.
