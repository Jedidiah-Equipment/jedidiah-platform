# Maintain Work Types

Inactive Work Types stay on old Jobs and are excluded from pickers.

1. In Jedidiah Contracting, open **Work types**.
2. Choose **New work type**, enter the **Name**, and choose **Save**. Names must be unique, ignoring letter case; a new Work Type is Active.
3. Open a Work Type to correct its **Name**. Changes save automatically; check the save status before leaving and use **Retry** if saving fails.
4. Turn **Active** off to stop offering it in pickers. It remains in this management list and on existing records.
5. Turn **Active** on again to offer it in pickers again.
