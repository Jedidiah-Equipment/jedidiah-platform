# Credits

Authored and maintained by Dean van Niekerk.

The standards/spec review axes are related to [Matt Pocock's code-review](https://github.com/mattpocock/skills/tree/main/skills/engineering/code-review), used in Dean's local review workflow. This skill adds a separate correctness axis, a headless Claude invocation, and pinned GitHub review publication. Matt's skill is not bundled or required here.

Uses [Anthropic Claude Code](https://code.claude.com/docs/en/cli-reference) and the [GitHub pull-request review API](https://docs.github.com/en/rest/pulls/reviews). Product names identify dependencies, not endorsement.
