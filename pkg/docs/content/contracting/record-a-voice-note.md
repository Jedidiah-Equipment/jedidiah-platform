# Record a Voice Note

A Voice Note fills a text box by speech instead of typing: a reading's comment, a Field Note's description, and every other multi-line text box in the Contracting app. The phone sends the recording for text and keeps none of it.

1. Hold the microphone under the text box and speak. The timer shows how long you have recorded; a Voice Note stops itself at 2 minutes.
2. Release the microphone. **Transcribing…** shows while the text comes back, and the text is added after anything you already typed.
3. Read the text and fix any wrong word or name before you save. Record again to add more.
4. Save the form as usual, for example **Save reading** or **Save note**.

The first time, the phone asks to use the microphone; allow it, then hold the microphone again. If you refused, allow the microphone for Jedidiah in the phone's Settings.

The microphone shows only while the phone is online, and never in the web app; offline, type the text instead. If **Transcription unavailable — type the note.** appears, type it.

Speak in whatever language you work in. The text keeps the language you spoke and is never translated, and mixed Afrikaans and English is fine. Zulu, Xhosa and Sepedi come out less accurately, so check those notes more carefully.

The corrections you make before saving teach the transcriber how names and local words are spelled, so later Voice Notes come out better.
