# Add a Custom Line to a Purchase Order

Use a Custom Line for a once-off item that will not be held as stock. If you expect to buy it repeatedly or count it in stock, create a Part instead.

## Steps

1. Open a Draft Purchase Order for the Supplier. The Supplier can have no Parts on file.
2. Click **Add custom line**. Enter a description, quantity, unit (such as `each` or `box`), and unit price. Enter a supplier code if the Supplier gave you one.
3. Review the order and **Preview PDF**. The Custom Line's description, optional supplier code, quantity and unit appear there; prices do not.
4. Have the order approved and send it to the Supplier as you would any Purchase Order. **Mark sent** requires a price on every line.

A Custom Line never changes stock or appears in On Order or the buy list. It can share a Purchase Order with Part Lines.
