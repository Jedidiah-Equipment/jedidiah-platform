# Run the Workshop queue

The Workshop queue is every Breakdown reported from the field, for the workshop manager to work through on the web.

1. Open **Workshop**.
2. Read the queue. It shows Not fixed and Fixing Breakdowns, newest first; a red flag marks Code Red and a green flag Code Green; sort the **Code** column to bring Code Red to the top, or filter it to one urgency. Choose **Not fixed** or **Fixing** to see only those, or **All** to include Fixed ones too, and choose it again to go back; a status button shows only while it has Breakdowns. To see only Fixed ones, filter the **Status** column. Search by machine, implement, Job, Farm, reporter, Mechanic or description, and filter the **Reported**, **Subject**, **Job**, **Farm**, **Reporter** or **Mechanic** column to narrow it further.
3. Check **Dispatch**. **+N on this Job** means other fleet on the same Job also has a Breakdown not yet Fixed: one trip can fix several.
4. Open a Breakdown. Read the **Report** and **Photos**; choose **Open in Google Maps** to see where it was reported. **Also open on this Job** lists the other Breakdowns on the same Job that are not yet Fixed, so one Mechanic can take them all.
5. The **Workshop** card is a timeline: **Reported**, **Mechanic**, **Fixing** and **Fixed**, with a tick on Fixed once it is done. On the **Mechanic** step, choose **Assign mechanic** (or **Change mechanic**) and pick the Mechanic who will fix it. You can also assign one straight from the queue.
6. Choose **Start work** on the **Fixing** step when the Mechanic starts. The Breakdown is Fixing.
7. Keep the conversation with the Foreman under **Notes**: write it and choose **Add note**.
8. Choose **Mark completed** on the **Fixed** step, write the **Close-out note** — what was wrong and what was done — and choose **Mark completed**. The Breakdown is then Fixed. A Breakdown can go straight to Fixed from Not fixed. Once Fixed, only notes can be added.

Foremen follow their own Breakdowns on the phone: see [Report a Breakdown](./report-a-breakdown).

## Report a problem on the web

1. Start from where the problem is:
   - In **Workshop**, choose **Report a problem**. Pick **Machine** or **Implement** and choose it; the line under it shows the Job it is on site on, which the report attaches to. **Already reported** lists its Breakdowns not yet Fixed: if the problem is there, open it and add a note instead.
   - On a Job, choose **+** under the Machine Assignment's timeline, then **Code Green** or **Code Red**. When the Machine tows an Implement, pick the **Machine** or the **Implement**. The Job is attached for you.
2. In **Workshop**, choose **Code Red** when it cannot work or **Code Green** when it can carry on for now.
3. Attach up to six photos if you have them, and describe the problem under **What is wrong**.
4. Choose **Report Code Red** or **Report Code Green**. No location is recorded. From **Workshop**, the new Breakdown opens; on a Job, it shows on the Machine Assignment's timeline, and its edit button opens it here.
