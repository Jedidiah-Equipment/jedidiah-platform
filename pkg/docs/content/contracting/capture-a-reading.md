# Capture a reading

1. Open the Machine and choose **Capture reading**, or start or stop a Machine from its Job.
2. Choose **Photograph meter**, allow camera access if asked, and keep all digits sharp inside the guide. Choose **Take photo**. The guide does not crop the photo.
3. Type the **Hour meter value**, including the decimal digit. If the camera is unavailable, continue without a photo: the reading will carry **Missing Photo Evidence**. **Minimum allowed** is the Machine's latest reading.
4. If the value is below the minimum, correct it or choose **The previous reading is wrong** to dispute that reading. An equal value is accepted.
5. Add a **Comment** if management should know something about this reading, such as a damaged meter or a replaced display.
6. Choose **Save reading**. The reading is saved on the server at once; if it is refused, the reason is shown and you can correct the value or dispute the previous reading.

**Minimum allowed** for a departure is the arrival you captured.

Capturing needs a connection. Management reviews photo verification on web; you do not need to wait for it.
