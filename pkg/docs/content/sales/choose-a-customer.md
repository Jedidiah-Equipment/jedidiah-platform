# Choose a Customer

When adding a Customer or raising a Quote with a new Customer on web or mobile:

1. Enter the company name, complete the form, and select **Save**.
2. If **Possible Customer match** appears, check the contact person, email and created date. Select **Use this Customer** to use the existing record.
3. If this is a different company with the same name, select **Create anyway**. Select **Go back** to return to the form without creating anything.

Names match ignoring case and whitespace; the Assistant uses an existing Customer unless you say it is a different company.
