# Keep a Field Note

A Field Note is a note you keep on this phone, typically when there is no signal, and act on yourself later. It never reaches the server and is never turned into a reading. Only a Voice Note recorded into its description leaves the phone: the recording is turned into text, and the description you save with it improves later Voice Notes.

1. Open **Field Notes** and choose **New Field Note** (the **+**).
2. Write what you need to act on later. Online, you can [say it as a Voice Note](./record-a-voice-note) instead.
3. Optionally, choose **Take photo** or **Choose from gallery** to add photos.
4. Choose **Save note**. The note is listed as Open.

Once you have acted on the note, open it in **Field Notes** and choose **Close**. **Field Notes** lists Open notes; filter to **Closed notes** to see the rest.

The orange dot on **Field Notes** shows while any note is Open. Open a note to add or remove photos or change its description. A Closed note shows **Reopen** and **Delete**. Each person who signs in on the phone sees only their own notes.
