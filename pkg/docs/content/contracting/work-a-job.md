# Work a Job

1. Open **Jobs**. Your assigned Jobs are listed.
2. Open the Job. Each Machine shows **Planned**, **Running**, or **Left site**.
3. To start a planned Machine, choose **Start — capture arrival** and [capture the reading](./capture-a-reading). Change the Implement or Driver first if they differ from the plan.
4. To stop it, choose **Stop — capture departure**.
5. To add a Machine that was not planned, choose **Add machine**, pick the Machine, attach an Implement if it tows one, confirm the Driver, and confirm with **Add machine**. It joins the list as **Planned**; start it as in step 3 when it arrives. A Machine still on another Job can be planned but cannot start until it leaves there.
6. A Machine that left may be added again with **Re-add machine**.

The Jobs screen needs a connection; without one, [keep a Field Note](./keep-a-field-note).
