# Work a Job

Open **Jobs** while connected before going into the field so your Jobs, Implements, and Drivers are saved on this phone.

1. Open **Jobs**. Your assigned Jobs are listed.
2. Open the Job. Each Machine shows **Planned**, **Running**, or **Left site**.
3. To start a planned Machine, choose **Start — capture arrival** and [capture the reading](./capture-a-reading). Change the Implement or Driver first if they differ from the plan.
4. To stop it, choose **Stop — capture departure**.
5. To add a Machine that was not planned, tap **+** beside **Machines**, pick it, attach an Implement if it tows one, confirm the Driver, and choose **Add machine**. It joins the list as **Planned**; start it as in step 3 when it arrives. Adding needs a connection. A Machine still on another Job can be planned but cannot start until it leaves there.
6. A Machine that left may be added again with **Re-add machine**.

Captures save on the phone and sync in order when a connection returns. A refused start appears in **Needs attention** and on the Job's Machine card.
