# Record feedback by voice

On the phone, the **Feedback** box can be filled by speech instead of typing. The mic is there in **Send Feedback** and **Send PO Feedback** on a Job. The recording is sent to be turned into text and is never kept. Typing works exactly as before.

1. Hold the microphone and speak. A Voice Note stops itself at 2 minutes.
2. Release the microphone. The text is added after anything you already typed.
3. Read the text and fix any wrong word or name; your corrections teach later Voice Notes how names are spelled. Record again to add more.
4. Choose **Submit Feedback**. It waits while a Voice Note is still recording or being turned into text.

The first time, the phone asks to use the microphone; allow it, then hold the microphone again. If you refused, allow the microphone for Jedidiah in the phone's Settings.

Voice Notes work only while the phone is online, and not in the web app. If **Nothing was heard. Try again closer to the phone, or type the note.** appears, record again closer to the phone, or type the feedback. If **Transcription is unavailable right now. Type the note instead.** or **Transcription unavailable — type the note.** appears, type the feedback.

English and Afrikaans work, mixed in one note too, and the text stays in the language you spoke; it is never translated. Other languages are not supported yet and come back wrong, so type that feedback.

See [Send Feedback on a Purchase Order](../inventory/send-feedback-on-a-purchase-order) for who sees Purchase Order feedback.
