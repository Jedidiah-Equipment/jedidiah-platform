# Add a Custom Line to a Purchase Order

Use a Custom Line for a once-off item that will not be held as stock; it never changes stock, and repeat purchases should become Parts.

## Steps

1. Open a Draft Purchase Order for the Supplier, with or without Part Lines. The Supplier can have no Parts on file.
2. Click **Add custom line**. Enter a description, quantity, unit (such as `each` or `box`), and unit price if you know it. Enter a supplier code if the Supplier gave you one.
3. Review the order and **Preview PDF**. The Custom Line's description, optional supplier code, quantity and unit appear there; prices do not.
4. Have the order approved and send it to the Supplier as you would any Purchase Order. A Custom Line can be sent without a price; it then shows **Not priced** on the order, and the order total reads **Not priced** too.

When it arrives, follow [Receiving a Custom Line](./post-a-receipt.md#receiving-a-custom-line).
