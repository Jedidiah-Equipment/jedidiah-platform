# Set up a Job

1. Open **Jobs**. Use Upcoming, Active, Looks finished, Awaiting pricing, or Awaiting invoice to find the Job's stage.
2. Choose **New job**. Select the **Customer**, **Farm**, and **Work type**, assign a **Foreman**, and add a description. If the Customer, Farm, or Work type is new, type its name and choose **Create** to add it without leaving the form. You can assign a Foreman later from Upcoming. Save the Job.
3. Under **Machines**, choose **Plan machine** for each Machine expected on site. Select its Implement and Driver. The Foreman can also add an unplanned Machine while working the Job.
4. When a planned Machine arrives, use the play icon beside **Arrival** on its card to **Start — capture arrival**. Enter its Hour Reading and attach a meter photo when available. The Job becomes **Active** when the first Machine arrives. It appears in **Looks finished** after every Machine has left.

When the work is done, [sign off the Job](./sign-off-a-job.md).
