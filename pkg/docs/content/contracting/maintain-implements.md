# Maintain Implements

1. Open **Implements** in Jedidiah Contracting.
2. Choose **New implement**, enter its **Code**, and choose or type an **Implement type**.
3. Choose **Save**. Codes display uppercase; a Code already used by another Implement is rejected regardless of letter case.
4. Open an Implement to change its Code, Implement type, or Notes. Changes save automatically; resolve any validation or save error before leaving.
5. To permanently withdraw it, choose **Retire implement**, enter a **Retirement reason**, and choose **Retire**. Its history remains available and it disappears from active pickers. Retirement cannot be undone.
6. Use **Delete implement** only for a never-used entry. If linked history blocks deletion, retire it instead.
7. Choose **Retired** in the fleet status filter to find retired Implements.

An Implement is an un-metered attachment: it has no hour readings, hourly rate, or availability of its own. Fleet changes require Contracting fleet management access.
