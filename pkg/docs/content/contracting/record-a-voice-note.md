# Record a Voice Note

A Voice Note fills a text box by speech instead of typing: a reading's comment, a Field Note's description, and every other multi-line text box in the Contracting app. The recording is sent to be turned into text and is never kept.

1. Hold the microphone and speak. A Voice Note stops itself at 2 minutes.
2. Release the microphone. The text is added after anything you already typed.
3. Read the text and fix any wrong word or name; your corrections teach later Voice Notes how names and local words are spelled. Record again to add more.
4. Save the form as usual, for example **Save reading** or **Save note**.

The first time, the phone asks to use the microphone; allow it, then hold the microphone again. If you refused, allow the microphone for Jedidiah in the phone's Settings.

Voice Notes work only while the phone is online, and not in the web app. If **Transcription unavailable — type the note.** appears, type it instead.

English and Afrikaans work, mixed in one note too, and the text stays in the language you spoke; it is never translated. Other languages are not supported yet and come back wrong, so type those notes.
