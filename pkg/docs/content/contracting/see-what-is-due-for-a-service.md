# See what is due for a service

The Services page lists the services Booked in, with the Machines due for a service pinned above them so no filter hides one; what makes a Machine due is on [Book a service](./book-a-service).

1. Open **Services**.
2. Read the highlighted rows at the top: each is a Machine due for a service, overdue first, with its latest reading and the hours to go or how far it is overdue.
3. When a Machine comes in, choose **Book a service** on its row, or choose **Book a service** and pick the **Machine**. Set the **Start date**, the **Mechanic** if you know it, and any **Notes**, then choose **Book service**. The Machine leaves the top and its Service Record shows below as **Booked in**.
4. To close the service when the Machine leaves, select its row to open the Machine and follow [Book a service](./book-a-service) from step 4.
5. Below the highlighted rows, read the services Booked in, newest first. To look back at closed services, pick **Closed** in the **Status** column filter. Search by Machine or Mechanic, and filter the **Machine** or **Mechanic** column to narrow it further. None of this hides the highlighted rows.
