# Maintain Categories

1. Open **Fleet → Categories** in Jedidiah Contracting. Use the kind filter to show only Machine or Implement categories.
2. Choose **New category**, enter its **Name**, choose its **Kind** (Machine or Implement), and choose **Save**. A name already used by another Category of the same kind is rejected regardless of letter case.
3. Open the Category to pick its **Icon** from the fleet glyphs and its **Colour** from the palette. Every Machine or Implement in the Category shows that icon in that colour. Changes save automatically.
4. Change the **Kind** only while no Machine or Implement uses the Category; once one does, the field is locked until they are moved elsewhere.
5. Resolve any validation or save error before leaving.
6. To remove an unused Category, choose **Delete category**. Categories linked to Machines or Implements cannot be deleted; move those entries to another Category first.

A Category carries no rate: pricing comes from the Rate Card. Machines take Machine categories and Implements take Implement categories; see [Machines](./maintain-machines) and [Implements](./maintain-implements).
