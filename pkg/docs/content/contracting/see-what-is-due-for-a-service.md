# See what is due for a service

The Services page lists every Service Record, with the Machines due for a service pinned above them so no filter hides one; what makes a Machine due is on [Record a service](./record-a-service).

1. Open **Services**.
2. Read the highlighted rows at the top: each is a Machine due for a service, overdue first, with its latest reading and the hours to go or how far it is overdue.
3. When a Machine comes in, choose **Record a service** on its row, set the **Start date**, the **Mechanic** if you know it, and any **Notes**, then choose **Record service**. The Machine leaves the top and its Service Record shows below as **Booked in**.
4. To close the service when the Machine leaves, select its row to open the Machine and follow [Record a service](./record-a-service) from step 4.
5. Below the highlighted rows, read the Service Records: Booked in first, then newest first. Choose **Booked in** or **Closed** to see only those, or **All** to see both, and choose it again to go back. Search by Machine or Mechanic, and filter the **Machine**, **Mechanic** or **Status** column to narrow it further. None of this hides the highlighted rows.
